# 06 Contribution Practice

This module turns reading into responsible contribution. Every ticket should reduce risk, follow existing patterns, and be easy for a maintainer to review.

Read in order:

1. [01-good-first-tickets.md](01-good-first-tickets.md)
2. [02-mid-level-feature-tickets.md](02-mid-level-feature-tickets.md)
3. [03-senior-build-projects.md](03-senior-build-projects.md)
4. [04-refactor-and-design-katas.md](04-refactor-and-design-katas.md)

Contribution rule: do not do drive-by refactors. Tie every change to a behavior, test, risk reduction, or documented learning value.
